# 🐞 Bug Reports

У цьому розділі зібрані приклади моїх баг-репортів, створених під час навчання Manual QA.

## 📋 Використані навички

- Створення Bug Report
- Визначення Severity та Priority
- Опис кроків відтворення (Steps to Reproduce)
- Очікуваний та фактичний результат
- Додавання доказів (Screenshots)
